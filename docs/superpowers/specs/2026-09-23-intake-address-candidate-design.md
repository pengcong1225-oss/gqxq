# 诉求入库地址候选提取与存量补提取设计

日期：2026-09-23。状态：业主已确认设计，待实施。

## 目标与边界

业主要求在诉求入库时从标题和正文提取位置，并对已有诉求批量处理。提取结果是**待核实地址候选**，不是来源原始地址、人工纠偏结论或地图坐标。测试使用虚构地址“点军区联棚乡示例小区18号1301”，必须截到房号且不能把燃气报装等后文并入地址；不在仓库中复制业主提供的真实住址。来源 `complaint.address`、人工纠偏后的地址和坐标均不得被机器候选覆盖。批处理不得向第三方地图服务发送住户地址。

同时澄清详情页口径：现有 `rule_confidence=0.72` 是敏感词未命中时的固定规则分值，`classify.v1+sensitive_word/3` 是分类规则版本与当时启用的 3 个敏感词条的组合标识，不是地址提取的置信度，也不是校准过的概率。

## 方案选择

1. **独立候选表（采用）**：按诉求存当前候选、证据片段、提取规则版本、输入指纹与更新时间。可与来源地址和人工结论严格隔离，支持重投更新和批量幂等。
2. 直接写 `complaint.address`：改动少，但会伪装成来源原值，也可能在重投时覆盖来源信息；不采用。
3. 写 `correction_item.new_value`：会与人工确认值的语义和生命周期冲突；不采用。

## 数据与接口

新增迁移创建 `complaint_address_candidate`，以 `complaint_id` 唯一，包含候选文本、证据片段、提取来源字段（title/content）、提取器版本、输入内容哈希、生成/更新时间；无可靠候选时不造记录。候选文本和证据遵守明确长度上限，接口不得返回完整原始报文。迁移仅建表，不在迁移中执行批量业务回填。

诉求详情 API 增加可空的 `addressCandidate` 对象。整体纠偏抽屉通过相同只读查询显示候选，位置组窗体允许操作员一键把候选填入**未确认**的地址输入框，再手动搜索定位并保存；不自动查询天地图，也不自动提交纠偏。若地址项已经确认，只展示候选与证据，不再提供覆盖操作。

提供仅管理员可调用的批量预览与执行接口。预览返回总数、可提取数、无候选数、会新增数、会更新数及少量脱敏示例，不写业务数据。执行分页/分批处理，返回处理与失败计数；按 `(complaint_id, 输入哈希, 提取器版本)` 判定幂等，重复执行不重复插入，不改人工字段。批量执行前界面展示范围与预览结果，要求明确确认；失败可重试。API 不回传整批私人地址。

## 提取规则

第一版使用服务端本地、确定性的规则提取，不调用外部模型或地图 API。输入为来源 `title`、`content`，优先保留含区县/乡镇街道/小区/楼栋/门牌/室号的连续地址片段；去掉“我是……的居民”“我家在……”等引导语及后续诉求叙述。来源显式 `address` 不参与候选提取，但可与候选并列展示供核对。规则无法可靠切分、出现多个互相冲突的位置或文本不足时返回无候选，不编造数值置信度。每个候选保留命中证据与 `address-extract.v1` 版本，方便复核与后续迭代。

## 写入时序与并发

- 新入库：在既有入库事务中完成诉求插入后，按标题/正文生成候选并 upsert，事务失败则一同回滚。
- 同报文重传：遵循原有幂等分支，不改候选。
- 有变化重投：仅标题或正文实际变化时重新提取；若结果不再可靠，应清除**机器候选**，保留来源地址和人工结论。候选 upsert/清除与来源更新处于同一事务。
- 存量批量：按稳定主键扫描并小批事务提交；处理单条时核对当前标题/正文的哈希，避免旧快照覆盖同时发生的重投。人工纠偏可以并行，不被批处理改写。错误隔离到批次，记录可重试结果；接口有权限和操作审计。

## 展示与口径

诉求详情将“规则预处理 置信度 72%”改为“敏感词规则分值：未命中固定 72% / 命中固定 88%”，解释它不是地址精度；若词表为空，应显示词表缺失/判定不可用，不把 72% 展示成可信概率。地址候选另设“待核实”标签，展示提取来源和规则版本，不显示未经验证的百分比。纠偏窗体将来源地址、机器候选、人工填写值三者明显区分。

## 验证与验收

- 测试先行：示例住址的准确截取、无地址、多个地址歧义、长正文、不得夹带诉求叙述；候选不覆盖来源地址/人工结论。
- 入库三分支：新建生成、同报文不变、正文变化重投更新/清除；事务失败回滚。
- 批量：预览只读、执行幂等、重复运行、并发重投保护、失败重试、权限与审计。
- 前端：详情标签准确，候选只在操作员明确选择时填入；地图检索和保存仍需单独操作。
- 运行完整 `npm run verify`、前端构建，并在非生产数据上做接口验收。真实存量执行前保留预览计数与备份/回退方案；本设计批准不等于立即修改真实库。

## 不在本次范围

不做自动地理编码、自动坐标填入、自动确认纠偏、外部模型调用、跨诉求地址推断，也不把敏感词规则分值改造成尚未校准的地址置信度。
