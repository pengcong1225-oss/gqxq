# 诉求位置线索分级提取设计

日期：2026-09-24。状态：待业主审阅；仅为设计，不授权执行真实库回填、推送或发布。

## 目标与已确认口径

诉求入库时从标题、正文提取有证据的位置；存量诉求可先预览再批量补提取。操作员应能区分可手动带入未确认纠偏表单的详细地址候选，以及只能辅助定位的乡镇、街道、村、社区、小区线索。多个地点相互冲突时全部留给人工判断。机器结果不得覆盖来源地址、人工纠偏值或坐标，不自动地理编码、定位或确认。真实诉求正文含个人信息，测试和报告只使用虚构文本或聚合计数。

## 现状与方案选择

现有 `addressExtract.ts` 规则要求区县、乡镇和门室号等片段连续出现。M12 `complaint_address_candidate` 每件诉求至多一条；新建和变化重投已在入库事务内同步该候选，详情页、整体纠偏页可读取它。2026-09-23 对本机真实库的只读预览为 0/464 可提取，未执行回填。把仅有“联棚乡”的结果放进此表，会与“可带入地址”的语义冲突；单条结构也无法保留多地点证据。

采用**保留 M12 详细地址候选 + 新增一对多机器位置线索表**。不改人工纠偏生命周期，不把线索序列化进单条候选；后者虽省迁移，却难以逐条展示冲突、追踪来源和安全重算。两类结果由同一版本化提取服务生成，但分别写入和展示。

## 官方名录与版本

名录限宜昌市乡镇、街道，作为本地只读、随代码发布的快照使用，生产请求不依赖外网。来源是[中国·国家地名信息库查询](https://dmfw.mca.gov.cn/9095/xzqh/getList?code=4205&maxLevel=3)；2026-09-23 读取到 13 个县级单位、110 个乡级单位，宜昌范围乡级名称无重名；点军区下“联棚乡”返回 `420504202000`，乡级九位码为 `420504202`。接口即使传无效年份也返回同样数据，故**不能**把请求中的 `year` 当作数据版本；快照须记抓取时间、源 URL、内容校验值和人工复核状态。入库前按[行政区划代码管理办法](https://www.moj.gov.cn/pub/sfbgw/flfggz/flfggzbmgz/202512/t20251204_528920.html)核对九位码与父级前缀，并与省民政厅当期公告核对。未经复核、下载失败或校验失败时保持已核准的旧快照，不静默换版。

名录仅用于**宜昌业务范围内**的精确名称匹配与上级区县提示，不声称全国唯一。更新快照需做新增、撤销、改名、代码变动和同名差异报告；提取器版本与快照标识一同参与重算判定。旧候选和人工结论不因换版被直接覆盖。

## 提取分级与冲突

1. **详细地址候选**：原文存在可可靠切分的居住地点及门室号，例如虚构文本“联棚乡示例家园18号1301”；允许依据唯一乡镇匹配提示所属区县，但候选文本只保存原文片段，推定的区县单独标注，不能伪装成原文。仍需操作员手动核对、搜索地图并保存。扩充“家园”等合理居住区后缀时须有边界测试，不能吞入后续诉求内容。
2. **乡镇／街道线索**：文本仅给出乡级名称，且名录中在宜昌范围唯一时，记录乡级码、所属区县及证据；不构造门牌或坐标。
3. **村／社区／小区线索**：可从原文截出明确地名，但没有可靠父级匹配时保留原文和“上级待核实”；只有与同一上下文的已识别乡镇形成明确关联时，才附加该父级，不把村、社区或小区名称本身当成乡级官方名录。

只记录肯定陈述中的地点；“不是在……”“原来住……”“转交到……”等否定、历史或非诉求地点不能直接当现址。若有多处彼此不兼容的候选，保留每条命中证据并计算诉求级“位置冲突”，不选最高分。重复提及同一地点可去重，但来源证据需能回查。无可靠命中就不造候选，不显示未经校准的百分比置信度。敏感词分类分值与位置准确性无关。

## 数据与接口

新增迁移创建机器线索表，按诉求一对多存储：线索类别、原文片段、标题／正文来源、证据位置或受限证据片段、规范化乡级码及父级区县码（可空）、父级匹配方式、提取器版本、名录快照标识、输入哈希、生成时间。机器行不允许人工修改；诉求级冲突状态由当前线索集合计算，不复制为人工确认值。迁移只改结构，不执行存量业务写入。现有 M12 表保持详细地址候选语义，并以兼容迁移增设可空的推定区县码、匹配方式和名录快照标识；旧记录这些字段保持空，不伪装成已校验结果。

诉求详情 API 增加 `locationClues[]` 与 `locationConflict`，保留现有 `addressCandidate` 并兼容增加推定区县元数据。详情页及整体纠偏窗体分区展示“详细地址候选”和“待核实位置线索”；线索显示类别、可核实的所属区县、原文证据及冲突标签，点击线索只查看证据。仅详细地址候选在地址项未确认、且整件诉求不存在位置冲突时提供显式“带入待填写地址”操作；该操作仍不搜索地图、不保存纠偏、不自动提交。冲突时两类结果只能查看，须人工重新填写和确认。权限沿用诉求详情及整体纠偏的既有授权；批量操作仅管理员可用。

## 写入、预览与失败处理

新诉求入库和标题／正文变化重投时，在既有事务内依据当前文本同步两类机器结果；相同报文重传不重复写入。同步位置线索时以受锁定的当前诉求文本重算整组机器行；输入哈希、提取器版本和名录快照标识均相同则不写。确需替换时只替换机器线索，不触及来源地址、人工纠偏或坐标。事务失败全部回滚。

存量预览只读，按稳定主键分页，返回总数、各级命中数、冲突数、无法定位数、预计新增／更新／不变／移除及错误数；示例只给序号、类别、动作和脱敏占位符，不返回姓名、手机号、原文地址或诉求正文。名录快照或提取器版本变化也应在预览中显示预计重算数量。执行入口须显示预览结果并再次明确确认；执行时逐件锁定后重算，逐件事务和审计，单件失败可重试且不阻断其余项。**预览不是执行授权**：在真实库执行前仍须单独备份、复核计数并取得明确决定。网络不可用时运行时使用已固化快照，不向地名库或地图服务发送诉求内容。

## 验收标准

- 纯规则测试覆盖完整地址、仅乡镇、仅村／社区／小区、重复提及、重名／无名录、否定与历史地点、多个冲突地点、长正文及边界截取；虚构“联棚乡示例家园18号1301”不得吞入后续报装叙述。
- 入库测试覆盖新建、同报文重传、变化重投、候选消失及事务回滚；人工字段始终不变。
- 名录测试覆盖 12 位响应到 9 位乡级码、父级校验、重复名称检测、无效年份不被当作版本、快照更新差异及离线运行。
- 批量测试覆盖预览绝对只读和脱敏、执行幂等、并发重投、逐件失败隔离、权限与审计；测试库验收后，真实库只先做预览。
- 前端测试确认线索不可直接带入地址，详细地址候选仅在未确认且无位置冲突时显式带入，地图搜索和保存仍须人工操作。

本设计不包含自动地理编码、自动补齐区县到地址原文、自动坐标/纠偏确认、外部模型推理或真实库立即回填。
