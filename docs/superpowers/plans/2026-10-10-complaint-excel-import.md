# 诉求 Excel 导入交付计划

用户提供的宜接就办综合查询 Excel 是输入格式依据。交付入口位于诉求总账：上传、校验预览、确认导入、查看结果。仅本地验收，不推送或部署；不调整现有账号密码，不替用户确认真实数据入库。

全局约束：使用已有隔离工作树；复用入站新增事务及留痕，已有案件不更新。同文件案件公文号重复取最后一行；任意错误阻止整批确认。来源导出中的处理结果保留为来源信息，不自动制造本平台交办、办结或企业匹配。

## Task 1：解析和批次事务

- Sol 6.1 high 解析子任务负责 complaintImportParser.ts、Python .xls helper 及解析测试；主会话负责剩余文件。
