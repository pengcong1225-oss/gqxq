# 交办推送与结果核验

在“敏感交办工作台”的“交办记录”中，先确认目标企业与截止时间，再点击“推送”。创建交办单不会自动外发。点击推送后，系统保存这次推送意图；“已排队”不表示对方已收到或创建任务。

刷新交办列表或重新打开详情，查看“外发状态”：

| 显示 | 含义与操作 |
| --- | --- |
| 尚未排队 | 尚未登记推送意图；有当前推送权限且交办有效时，可点击“推送”。 |
| 已排队 | 推送意图已保存，等待处理；请刷新查看，不需要反复点击。 |
| 发送中 | 正在处理，尚未确认对方创建任务；等待后刷新。 |
| 已确认创建 | 已核验填报任务号并关联本交办；可查看企业填报进度。创建任务不代表诉求已办结。 |
| 结果未知 · 需人工核验 | 外部可能已经创建任务，但尚无可信确认。记录原请求号，联系管理员核验外部任务；不要另建交办或换号重发。 |
| 失败／已停止 | 对方明确拒绝，或交办已取消、不再允许新发送。请核对错误码、交办状态、配置及原请求。 |

第一次推送后，原请求号和原始报文保持冻结。不能修改报文后沿用原号重发，也不能换号“解决”未知结果。如果实际提供方已确认安全恢复契约，页面才会允许通过“重推”核验并恢复；恢复仍使用原请求号和原报文。没有确认契约时，系统保留“需人工核验”，不会假装查询成功。

恢复能力和契约版本也随入队意图冻结。后来修改配置，不能自动把既有未知任务变成可以安全重发的任务；目标或恢复契约不匹配时仍需人工核验。已严格绑定的真实任务事实可帮助原记录确认结果。

旧记录首次纳入恢复时也可能显示结果未知，因为历史记录没有完整证据证明请求从未发出。请按原请求核验，不重新编号。若管理员核验获得外部任务关联，应通过双方已确认的关联或回传流程恢复；本页面没有凭手工输入任意任务号强制确认的入口。

取消发生在发送检查之前时，系统不再发出新请求；已经在途的请求仍可能返回结果。晚到的历史结果只关联原交办，不会推动新一轮交办的诉求状态。创建任务、企业填报审批、诉求来源状态和本系统人工办结各有自己的条件。

每次新的推送、重推和读取，都按当前账号权限与当前诉求范围检查。权限或范围变化后，按钮和直接接口会同步受限；此前已授权且已保存的推送意图仍由服务端核对原交办有效性后处理。

本功能的本地测试不代表实际提供方联调通过；外部接口版本与恢复契约仍需双方确认。
