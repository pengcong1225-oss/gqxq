# 位置组纠偏使用说明

在“整体纠偏”选择诉求，点击“打开位置组纠偏”；也可在诉求详情的“GIS位置”点击“前往位置组纠偏”。只有拥有“诉求纠偏”权限、诉求在授权范围内且位置组仍有待处理项时，才能提交。位置组全部处理后，不提供任意重新编辑入口。

1. 对照窗体上方的当前有效值，核对区划、地址、经纬度、行政网格和小区。区划名称由登记区码确定；小区必须属于所选行政网格，网格必须属于所选区划。同名候选按稳定编码区分，请人工选择。
2. 经纬度须成对填写或清空。地址留空表示清空。地图搜索和点选只回填草稿，仍须人工核对；地图或地址服务不可用时，可继续人工录入，暂时无法确定的项也可取消提交、保留待处理。
3. 选择坐标系状态并说明来源。旧坐标、天地图搜索结果和地图点选默认“未核实”。有明确 WGS84 资料时，可选择 WGS84 并填写来源；系统将其记录为操作者声明，不代表地图服务已认证。修改手填坐标后，坐标系状态会恢复为“未核实”。
4. 填写核对依据，点击“保存位置组”。区划、地址、坐标、网格、小区及坐标来源一次提交；校验或保存失败时整组回滚，不会只保存部分字段。组内已处理成员如有变化，会保留旧决定和新依据；未变化成员保留原决定，其他纠偏项不受影响。

当同一诉求正被责任企业分配、责任纠偏或交办等操作持锁时，位置组提交也可能立即返回409“正在被其它操作修改”；本次位置组事务完整回滚，不自动重放旧输入。遇到该提示或“已被其它窗口修改”时，未提交输入和依据会保留。点击“刷新核对（保留草稿）”，对照最新有效值及保留输入后再提交，不要直接覆盖其他人的更改。

保存结果会区分“空间复核通过”和“空间依据尚未核实”。空间判断采用保存当天（上海时区）的实际生效覆盖。坐标系未知、无生效区间、覆盖仅为草稿或边界缺失时，系统无法作空间判定；不会把未知当作坐标错误，也不会把人工保存称为已完成空间复核。这不证明诉求发生时的历史网格关系。

人工保存的有效位置及其来源说明会受到保护。来源系统后续重投会保留人工值，同时另存收到的来源快照，供核对追溯。位置组处理不会直接办结诉求；进入分析库仍须全部纠偏处理完毕且曾有交办。
