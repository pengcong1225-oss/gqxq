## 排期原则

1. **触发批次与推进批次分开**：卡外部的不占开发窗口，列触发条件，外部一到立即插入；
2. **批次粒度 = 一次可独立验收的闭环**：开发 + 本机门禁全绿 + 云端部署（沿用 archive+scp+compose 通道）+ 知识库回填，一次走完；
3. **每批次开工前一句话裁定，开工后生产写按既定授权执行**；
4. 工期按本项目实际节奏估（近三日完成 3 个开发批 + 2 次云部署），单位"日"指日历日、含验证。
