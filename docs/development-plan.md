## 技术架构概览

### 前端
- 框架: React 18 / Vue 3 + TypeScript
- UI库: Ant Design 5 / Element Plus
- 图表: ECharts 5
- GIS: 天地图 JavaScript API v4.0 + Turf.js
- 状态管理: Zustand / Pinia
- 构建: Vite 5

### 后端
- 框架: Spring Boot 3.2 + JDK 17
- 微服务: Spring Cloud Alibaba (Nacos + Sentinel + Gateway)
- ORM: MyBatis-Plus
- 安全: Spring Security + JWT
- 工作流: Flowable 6.8
- 任务调度: XXL-JOB
- 消息队列: RocketMQ 5.x
- NLP: Python FastAPI + PaddleNLP

### 数据层
- 关系数据库: PostgreSQL 15 + PostGIS 3.4
- 缓存: Redis 7.x
- 搜索: Elasticsearch 8.x
- 对象存储: MinIO
- 部署: Docker + Kubernetes

### 并行开发策略

Phase 3 (NLP/交办) 和 Phase 4 (企业/网格/热力图) 可由两个团队并行开发，在Phase 5开始前完成即可。

开发团队建议配置：
- 前端组: 3-4人 (2人管理后台 + 1-2人大屏)
- 后端组: 3-4人 (Java Spring Boot)
- NLP组: 1-2人 (Python)
- 测试: 2人
- DevOps: 1人
