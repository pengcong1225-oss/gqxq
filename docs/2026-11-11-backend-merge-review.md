# 后台同步分支与交付归档核对

本轮以 `sync/latest-source-20261111`（原起点 `c4154e9`）为实施基线，与 `migration/2026-11-01-delivery`（`ca92f4e`）逐项对照。保留同步分支已有修改，只迁入明确缺失的能力；不整体合并归档分支，不覆盖当前公共事业接口，不开发大屏。

| 标书/业务要求 | 同步分支原状 | 本轮处理 |
|---|---|---|
| 来源办理全过程及节点联系方式 | 有查询和表格，缺签名快照入口及联系方式权限投影 | 补受授权范围约束的签名接收、版本冲突/幂等、来源时间清空语义、当前及历史脱敏；详情展示联系方式 |
| 外部回访、满意度证据 | 有人工回访，缺来源回访可信绑定和历史明细 | 补签名回访接收，锁定目标诉求授权，不允许同一回访编号改绑；补当前及历史明细 |
| 采购统计与报告口径 | 默认候选分析口径，不等同来源明确办结口径 | 增加可选采购口径及报告模板；宜接就办/水气/completed/同步证据/来源时间共同判断，冻结快照及回访证据，旧快照不回查补证 |
| 企业与服务网格资料导入 | UI可维护，新字段未贯通导入模板 | 补企业展示字段、网格员姓名/联系方式，CSV/XLSX预览与保存；旧模板保留已有值，来源受控字段不覆盖 |
| 本系统人工办结 | 有API和状态，缺详情操作入口；可能复用旧轮审批 | 增加确认入口及依据输入；锁定最新交办、已应用的最终审批和本轮处置结果纠偏证据 |
| 真实主账四场景预警、历史/五季研判 | 专题支持模拟与独立数据集导入，未连通真实主账规则服务 | 迁入后台规则、预警与历史研判适配，复用采购统计快照，保留现有专题；无正式证据时显示不足，不填充模拟事实 |
| 完善地址/纠偏 | 详情已按诉求跳转纠偏，支持重新核对已确认位置 | 保留现有实现，不重复引入归档地址编辑器 |
| 停水停气、施工、停供超时回推、敏感交办 | 已有公共事业真实接口、修订历史、审批及反馈链 | 保留当前utility及交办实现；不迁旧停供来源/旧反馈worker，避免双链路 |
| 热力图、大屏及规则管理分工 | 后台规则及数据管理已存在，大屏源码另目录 | 本轮只补后台；既有大屏仅做构建和契约回归，不宣称大屏正式交付 |

## 测试与迁移

默认 `npm run verify` 检查两端类型、门禁、全部后端单元测试、后台交互和既有大屏契约。数据库测试单独显式启用，全部使用本机独立MySQL实例及合成记录；不读取业务`.env`，不接触业务数据库。

新增迁移承接历史独立SQL、后台支持存储、字段及权限修复，保留原迁移历史；完整链从无数据的外部DDL基线执行，并验证第二次执行无重复变更。对不兼容列/索引明确失败，不静默改写已有数据。数据库联调覆盖来源签名/授权/修订、导入预览→提交、敏感词扫描与审批回调重放。

门禁逐页声明真实/模拟/混合来源，未知页面失败，混合页面必须有可见模拟标识；保留假总数、假成功、隐式模拟回退及破坏性DDL拦截。大写字面量启发式警告单列，不等同门禁失败。

最终整体验证：后端263项、后台交互43项、既有大屏契约3项、迁移及新接口/导入/预警数据库16项、敏感词及回调数据库10项全部通过，均无跳过；两端类型检查及G1门禁通过（0失败，100条大写字面量启发式警告）。43个迁移完整执行，第二次0变更。测试环境不读取业务环境文件，不加载正式凭据。

后端、后台前端及既有大屏均在从暂存源码导出的干净目录构建通过；无运行环境配置，地理编码缓存由空示例初始化。构建不依赖本地私有数据。大屏构建仅为既有代码兼容回归，不替代地图引擎或生产验收。

自动预警默认关闭；部署时需发布正式规则，指定有全域及相应权限的专用账号，再开启定时核算。每轮校验最新账号和权限，重复运行幂等，执行中停用配置则整事务回滚。详见 [真实主账预警与研判](../server/docs/business-assessment.md)。

## 交付边界

合并代码不等于生产发布。本轮不迁移生产库、不发送真实交办/回推、不替换生产配置。上游正式密钥、来源字段映射及实际数据质量仍需部署联调；回访跨来源优先级沿用归档政策并明确待业务确认。

只提交源码、迁移、文档和合成测试/模板。不提交环境配置、真实诉求/联系人、私有地理编码缓存、数据库备份、日志、依赖、构建包。原实施目录及既有生产配置保持原样。授权地图引擎仍按原同步说明在仓库外管理。
