# category / b4-v1

- 字段：规则
- 模板类型：category / b4-v1
- 样例：全部虚构。导入前删除样例；引用对象需先导入。
- 步骤：下载 → 文本填写 → 预览 → 核对差异 → 确认 → 查询批次
- 约束：全批原子；有错误不能确认；10MiB / 2000行；24小时保留
- 空值：缺少可选列保留；提供空列清除可空文本；不删除文件缺少的对象
- 顺序：字典类型→条目/分类→企业→户数/映射→行政网格→小区→服务网格→覆盖/边界
- templateVersion：必填，固定 b4-v1；旧版本请重新下载
- code：必填稳定编码，作为文本读取，不能改绑
- label：必填标签，最多128字
- parentCode：空为根项；小类填写同类型父项编码，仅两级，支持同批新父项
- sort：必填整数，范围 -1000000 至1000000
- status：必填 enabled/disabled；停用含小类的大类需明确 cascadeDisable
- published：必填 true/false；已发布对象不会退回草稿
- cascadeDisable：必填 true/false；停用含子项对象需显式确认
